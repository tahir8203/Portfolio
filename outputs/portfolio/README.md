# Muhammad Tahir Mehmood — Portfolio

A responsive portfolio with a light violet, blue, and teal design, supplied portrait, scroll reveals, hover effects, active navigation, and reduced-motion support.

Open dist/index.html locally, or serve the dist directory. All deployable files are in dist. Edit index.html for content, style.css for appearance, and script.js for animation and navigation behavior.

Content is based on the supplied CV and public GitHub profile tahir8203. The downloadable CV is the original supplied PDF. Google Fonts load online with system font fallbacks.
